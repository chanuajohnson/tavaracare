## Problem

Two bugs in the **Receipt** generated by `DocumentGenerationMenu` → `generateReceiptPDF`:

1. **Payment Date is always "today"** — there is no UI prompt for it. `generateReceiptPDF` falls back to `format(new Date(), ...)` whenever `data.paymentDate` is undefined, and `DocumentGenerationMenu` never sets it. So receipts you generate today (May 14) for payments made on May 1, May 7, or April 16 all show "May 14, 2026".

2. **Receipt is missing the line-item table** — `generateInvoicePDF` calls `buildLineItemsTable(data)`, but `generateReceiptPDF` only renders the green "Payment Received" summary box plus an optional subscription includes line. The selected services from the picker are passed in but never drawn on the receipt PDF, so the document shows only "Care Plan: Care Services" with no breakdown matching the invoice.

## Fix

### 1. Prompt for payment details before generating a receipt

In `src/components/admin/care-plans/DocumentGenerationMenu.tsx`:

- When the user clicks **Generate Receipt**, open a small modal (shadcn `Dialog`) instead of calling `generateReceiptPDF` immediately. The modal collects:
  - **Payment Date** (date input, required, defaults to today)
  - **Payment Method** (select: Bank Transfer / Cash / Cheque / Other, defaults to Bank Transfer)
  - **Amount Paid (TTD)** (number, optional — defaults to computed total of selected items so backdated partial payments are supported)
- On confirm, pass `paymentDate`, `paymentMethod`, and `amountPaid` into `getData()` overrides and call `generateReceiptPDF`.
- Quote and Invoice flows are unchanged.

### 2. Render the selected services as line items on the receipt

In `src/services/care-plans/invoiceService.ts` → `generateReceiptPDF`:

- Insert `buildLineItemsTable(data)` between the green "Payment Received" summary and the subscription includes / signature blocks (same component the invoice uses, so the selected services display identically).
- The "Amount Paid" inside the green box continues to show the user-entered amount (which may differ from the line-item total when partial). When `amountPaid !== total`, append a small "(partial payment)" note next to Amount Paid for clarity.
- No change to `buildDefaultCareBillingData` — selected line items already flow through `additionalLineItems`.

### Files touched

- `src/components/admin/care-plans/DocumentGenerationMenu.tsx` — add receipt-details dialog + state, route Receipt button through it.
- `src/services/care-plans/invoiceService.ts` — add `buildLineItemsTable(data)` call inside `generateReceiptPDF`, plus partial-payment note.

### Out of scope (not touched)

- `receiptService.ts` (the work-log/payroll receipt generator) — different surface, not used here.
- Quote and Invoice PDFs.
- Database schema, RLS, or any other admin/family pages.

### Verification

- Generate a receipt today for "paid on 2026-05-01" → PDF shows Payment Date = May 1, 2026 and the same line items as the invoice for the same selected services.
- Repeat for 2026-05-07 and 2026-04-16.
- Generate with all services unchecked except subscription → receipt shows only that line, payment date honored.
- Enter a partial Amount Paid (less than total) → "Amount Paid" shows the entered figure with a "(partial payment)" note; line items still total to the full selection.
